# Ира Пицца Коин

Урок-игра по Python в пяти сериях. Открыть: https://vaxavan.github.io/ira-pizza-coin/

1. **Пицца** — табло на ленте: префиксные суммы. Босс — лучшая смена из K часов на 60 000 часах.
2. **Город** — табло на карте: двумерные префиксные суммы. Босс — 50 000 вопросов о районах карты 1000 × 100.
3. **Доставка** — метки +1 и −1: разностный массив, табло наоборот. Босс — акции и вопросы бухгалтера: нужны и метки, и табло.
4. **Вывеска** — строки: индексы и срезы, upper/lower/capitalize/title, count/find/in, replace, split/join, isdigit/startswith, палиндромы. 18 заказов — шесть приёмов по три похожих (почти готовый код → половина → своя программа). Босс — сжатие ленты кассы до 100 000 букв.
5. **Склад** — множества: len(set), sorted(set), «уже было?» через seen и in, пересечение &, разность -, объединение | и ^. Тоже шесть приёмов по три заказа. Босс — первая повторная карта среди 100 000: поиск по списку не успевает, множество успевает.

Серии 1–3 открываются по очереди. «Вывеска» и «Склад» открыты сразу, у них свой счётчик прогресса.
Встроенный Python (Skulpt) не понимал русские буквы в title, swapcase, isalpha, isalnum, isupper, islower, istitle — страница чинит эти методы при загрузке, они работают как в настоящем Python. Прогресс хранится в браузере ученика (ключ `pizzacoin-v6`).
Если ученик уходит на другую вкладку, страница говорит «Ира, не списывай!» (не больше 3 раз за день), а код, скопированный не на этой странице, в задачу не вставляется.
